# OpenAPI Reference

This is the complete OpenAPI 3.1 contract for the authenticated API used by
axkdeck. It is rendered from the same checked-in contract that native builds
and generated TypeScript declarations validate.

The interactive reference opens in a dedicated full-width view so its endpoint
navigation, documentation, and request and response examples remain readable.
