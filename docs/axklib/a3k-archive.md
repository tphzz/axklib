# A3K Volume Archives

A3K archives bundle A-series sampler content for transfer rather than reproducing
a disk filesystem. They are distinct from axklib's [AXK Portable Object Packages](portable-packages.md).

For the A3K archive file format, container layout, and index-record format, see
[Seclorum's a3kPackLab project](https://github.com/seclorum/a3kPackLab).

Seclorum is credited for documenting this format. Axklib intentionally does not
duplicate that documentation here.
